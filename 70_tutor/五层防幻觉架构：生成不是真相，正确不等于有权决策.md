# 五层防幻觉架构：生成不是真相，正确不等于有权决策

## 一句话先懂

防幻觉不是要求 AI 永不犯错，而是把 AI 的输出降为候选：只有通过数据证据、确定性校验、历史重放和人工金标准的内容，才可以逐级升级为事实、预测依据或决策。

## 大白话解释

把 AI 想成一名速度极快的记者。它擅长搜索线索、组织材料和提出解释，但仍可能听错、记错、把猜测写成事实，或者拿事后消息解释当时发生的事。

可靠的编辑部不会只在记者桌前贴一张“禁止写错”的标语，而会建立制度：

1. 记者负责写候选稿，不负责宣布终审事实；
2. 每个事实都要有采访记录、原文或数据库行；
3. 编辑按固定规则核对数字、人物和时间；
4. 复盘过去报道时，只允许使用当时已经公开的材料；
5. 模糊判断由人工定义标准和处理争议；
6. 没有通过验收的评分只能是意见，不能自动发稿或阻断业务。

因此，真正的目标不是制造一个“永远正确的生成器”，而是让错误即使被生成，也难以连续穿透所有防线并获得决策权。

## 第一性原理推导

先从五个不可再简化的事实出发：

1. `LLM（Large Language Model，大语言模型）`首先是根据上下文预测文本的概率生成器，流畅度不等于真实性。
2. 市场数据、公告时间和公司事实存在于模型外部，必须由外部记录提供。
3. 事实正确不代表解释正确。例如“成交额增加 20%”为真，不能自动推出“主线已经切换”。
4. 历史上解释得通不代表未来有效。看完结果再总结的规则可能包含前视偏差或过拟合。
5. 能给出意见不等于拥有执行权限。一个未经校准的分数不能自动阻断交易、修改知识库或升级硬规则。

由此可以逐步推出：

```text
模型不能自己证明自己的文本为真
→ 需要模型外部的数据证据
→ 有证据仍可能引用错、用晚或归类错
→ 需要可重复的确定性校验器
→ 单次校验正确仍不能证明规则可泛化
→ 需要严格时点的历史重放和样本外测试
→ 模糊标签与争议样本仍缺少统一目标
→ 需要人工金标准定义边界
→ 最后还要单独决定系统可以获得多大权限
```

## 技术映射

| 层 | 核心职责 | 主要防线 | 固有边界 |
|---|---|---|---|
| 生成器 | 提出候选事实、解释、预测和缺口 | 扩大召回、组织语言、防止遗漏 | 会编造、误归因或过度推断 |
| 数据证据 | 提供模型外部可观察记录 | 约束数字、实体、来源和时间 | 来源本身可能错误、冲突或缺失 |
| 确定性校验器 | 用代码执行可重复的是/否检查 | 数值一致、时点截止、字段类型、规则来源 | 难以独立判断复杂因果与模糊语义 |
| 历史重放 | 只用当时可得信息重演判断 | 发现前视、过拟合、评分倒置和周期失效 | 历史有效仍不保证未来制度不变 |
| 人工金标准 | 审定可信参考答案和争议边界 | 定义阶段、主线、命中等模糊标签 | 人也有偏差，需要复核和分歧记录 |

五层之外还有一个独立维度：`authority（权限）`。系统即使在某些样本上表现不错，也必须经过预注册验收，才能从“候选意见”升级为“自动动作”。

### 四种容易混淆的幻觉

1. **事实幻觉**：数字、实体或事件写错。主要由数据证据和数值校验约束。
2. **时间幻觉**：使用当时尚不可知的信息。主要由 `PIT（Point-in-Time，时点可得性）`、截止时间和历史重放约束。
3. **认识论幻觉**：把解释或猜测冒充事实。主要由事实、推断、预测分层和阈值来源约束。
4. **权限幻觉**：把未经验证的评分当成裁判或硬闸门。主要由校准测试和权限隔离约束。

## 术语对照

- `grounding（证据落地）`：把生成内容绑定到模型外部、可追溯的来源。
- `deterministic verifier（确定性校验器）`：相同输入必定得到相同检查结果的代码或规则。
- `PIT（Point-in-Time，时点可得性）`：信息在历史上的哪个时间点已经能够被当时的使用者知道。
- `historical replay（历史重放）`：冻结历史时点，只使用当时可得信息重新执行判断流程。
- `gold standard（人工金标准）`：由人工审定、用于评测系统的可信参考答案或标签。
- `calibration（校准）`：检查系统给出的信心与真实命中概率是否匹配。
- `decision eligibility（决策资格）`：某个信号或评分是否被允许触发自动动作。
- `defense in depth（纵深防御）`：假设每层都会失败，用多层独立防线降低错误穿透概率。

## 本轮场景对照

金融 Agent 输出：

> 储能成交额增加 20%，属于健康分歧，明天会回流，A 公司是最强标的。

这句话不能整体打一个“正确/错误”标签，而应拆成不同地位：

| 声明 | 类型 | 当前可用的验证 |
|---|---|---|
| 成交额增加 20% | 观察事实 | DuckDB、原始字段、来源时间和数值一致性 |
| 属于健康分歧 | 解释或阶段标签 | 确定性特征、替代解释、人工金标准 |
| 明天会回流 | 未来预测 | 严格 PIT 历史重放、样本外盲测和概率校准 |
| A 公司最强 | 标的选择 | 候选池完整性、排序规则和后验收益 |

本轮本地 Agent 的第一批改造主要完成：

- 证据必须记录来源时间和支持、反证方向；
- 经验阈值必须标明经验性质，不能冒充固定规则；
- 阶段判断必须暴露特征与规则编号；
- 未经盲测的评分固定为 `decision_eligible=false（无决策资格）`；
- 市场、方向、标的和证伪分别统计，不能由总分掩盖弱项。

这些改造提高的是可审计性和错误暴露能力，尚未证明现状描述、历史回溯或未来预测已经更准确。

## 替代方案与取舍

| 方案 | 优点 | 主要问题 |
|---|---|---|
| 强提示词要求“禁止幻觉” | 成本低、实施快 | 模型仍可能自信违规，缺少外部约束 |
| 只做 RAG | 能补充外部材料 | 可能检索错、引用错、混淆时间或错误推导 |
| 用另一个 LLM 当裁判 | 能处理模糊语言 | 两个模型可能共享偏差，结果也不确定 |
| 全部写成硬规则 | 可重复、易审计 | 长尾覆盖差，规则容易僵化 |
| 全部交给人工 | 能处理复杂语义 | 慢、贵，而且不同人标准不一致 |

合理选择不是押注其中一个方案，而是让生成器负责覆盖、数据负责事实、代码负责可判定约束、历史负责泛化检验、人工负责模糊边界。

## 边界与反例

- 证据绑定不保证证据本身正确；仍要处理来源质量、冲突和缺失。
- 确定性校验通过只说明满足已写出的规则，不代表因果关系成立。
- 历史回放表现好也可能是过拟合；需要时间隔离的样本外测试和滚动窗口。
- 人工金标准不是绝对真理；应保存审定依据、复核人和分歧。
- 防幻觉不等于预测更准。它首先阻止未经证明的内容伪装成事实或获得过大权限。
- 五层不要求所有小任务都同样复杂。低风险、可逆任务可以轻量化；高风险和不可逆动作才需要更严格的门槛。

## 可复用检查清单

面对一条 AI 结论，依次问：

1. 它是观察事实、解释、预测，还是动作建议？
2. 每个数字和实体能否定位到模型外部证据？
3. 证据在目标截止时间前是否已经可得？
4. 哪些检查可以写成相同输入、相同输出的代码？
5. 阈值来自固定规则、回测、机械推导，还是经验？
6. 是否在严格历史时点重放过，而不是看完结果后解释？
7. 是否有独立样本证明信心能区分命中和未命中？
8. 模糊标签由谁定义，争议样本如何记录？
9. 当前证据最多允许它获得什么权限？
10. 即使所有检查通过，仍有哪些错误无法被当前系统发现？

## 自测题

数据库已经证明“某板块成交额增加 20%、涨停数增加 3”两个数字完全正确。AI 随后说：“主线已经切换到这个板块，明天必然继续上涨。”此时系统可以把什么当作硬事实？

<details>
<summary>参考答案</summary>

只有两个已校验数字可以成为硬事实。“主线切换”仍是解释，需要确定性阶段定义、替代解释和人工金标准；“明天上涨”仍是预测，需要严格 PIT 历史重放、样本外验证和校准。事实正确不能自动把后续推断与预测一起升级。

</details>

## 跨领域同构

- **新闻编辑部**：记者写候选稿，采访记录证明事实，编辑核验，主编决定发布权限。
- **医疗辅助诊断**：检查结果是事实，诊断是推断，疗效是预测，处方权是权限。
- **信贷审批**：收入和负债是事实，风险等级是模型判断，违约率是预测，拒贷是受监管的动作。
- **软件交付**：代码生成器负责候选实现，类型检查和测试负责可判定错误，回归测试负责历史行为，人工评审负责设计边界，部署权限独立控制。
