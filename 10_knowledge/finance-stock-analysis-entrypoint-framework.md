# 金融个股与题材完整分析路径

用于回答“深挖某股 / 怎么看某股 / 还有没有上涨空间 / 从哪些视角分析”。

核心路径：公司本体 -> 产业链暴露 -> 证据层 -> 高位主线反证 -> 大盘流动性 -> 市场风格 -> 行业容量 -> 题材结构 -> 个股相对强度 -> 逻辑生命周期四问 -> 二阶导 -> 条件化结论。

## 十二个切入视角

1. 公司本体：主营、产品、客户、收入结构、毛利率、产业链上下游位置和报表传导。
2. 产业链暴露：需求增长、涨价、国产替代、扩产、缺货、技术路线变化；区分一阶和二阶/三阶受益。
3. 证据层：L1 观点叙事、L2 公司基本面、L3 公告/订单/认证/量产/客户验证、L4 盘面强度。
4. 高位主线反证：AI 硬件、CPO、PCB、半导体、存储等高位主线要看边际预期、流动性、证据硬度和位置约束。
5. 大盘与流动性：大盘阶段、成交额、20 日量能回归、指数/周均线偏离、涨家数、涨停跌停、涨家数 MA5。
6. 市场风格：大成交趋势、情绪连板、低位切换、高位抱团、防御避险、小票修复、容量核心虹吸。
7. 行业容量：容量前三申万一级、目标所属申万一级、成交占比环比、所属行业涨停结构。
8. 题材结构：所属题材、双红、双红演变、新高集群、涨停热度、同题材前排。
9. 个股相对强度：成交额、流动性、加权涨幅、3/5/10 日相对强度、新高/涨停、分歧日抗跌、回流日领先、强势股榜位置。
10. 逻辑生命周期：用四问判断阶段和状态。
11. 二阶导：从目标股反推真正瓶颈和更优表达。
12. 条件化结论：当前身份、置信度、升级条件、降级/证伪条件和后续跟踪指标。

## 逻辑生命周期四问

1. 生命周期哪一段：新出现 / 旧逻辑唤醒 / 升温验证 / 加速定价 / 高位分歧 / 衰退观察 / 证伪退出。
2. 相比昨天或过去 N 天的变化：证据层是否升级，盘面强度是否增强，强势股是否扩散，叙事是否升温，旧材料是否被重新验证。
3. 是否真正产生过市场价值：CAR、相对强度、成交额边际、强势股扩散、涨停扩散、回撤与半衰期；缺数据必须写缺口。
4. 如何升级、降级或证伪：什么信号让它进入加速定价，什么信号让它降级为衰退观察，什么信号触发证伪退出。

视角是硬约束，输出不是硬模板；回答要自然成文，但不能漏掉关键判断。
