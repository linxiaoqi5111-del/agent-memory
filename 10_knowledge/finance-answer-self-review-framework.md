# 金融问答自审框架：质检器与用户影子反驳

用于提升金融 agent 回答稳定性，防止“知道方法论但输出时漏视角、模板化、孤立看个股”。

## 核心流程

当前版本采用“初稿生成 + 二次反驳/重写”：

1. 先按完整分析路径生成初稿。
2. 对个股问题注入确定性数据块：D1 市场价值与替代队列、D2 客户证据硬度、D3 二阶导研究队列。
3. 第二次 LLM 调用模拟用户影子反驳，追问是否模板化、是否孤立看个股、证据是否够硬、生命周期是否完整、是否找到更优表达。
4. 若有缺口，二次重写最终稿。
5. 只输出最终答案，不输出质检过程或审稿过程。

## 结构化数据块

- D1 市场价值与替代队列：回答“市场有没有真的创造价值”，覆盖区间涨幅、峰值涨幅、峰后回撤、收益保留率、半衰期代理、题材状态、相对强度和同题材强势替代表达。
- D2 客户证据硬度：回答“客户/订单/量产证据到底多硬”，把证据分成硬证据、候选证据、弱证据/研报推断、反证/缺口。硬证据可支撑当期逻辑，候选证据只能支撑跟踪假设，弱证据不能直接当作基本面兑现。
- D3 二阶导研究队列：回答“如果目标不是最优表达，研究应该发散到哪里”，拆成 P0 盘面已选择的强势替代表达、P1 目标股再升级条件、P2 产业瓶颈补盲，并附带反向观察。

## 质检器

- 覆盖率：十二个切入视角不能漏，缺数据要写缺口。
- 第一性原理：解释资金为什么选择/不选择，产业事实如何传导到收入、毛利率、订单、产能或估值预期。
- 盘面融合：大盘阶段、成交额/20日量能、涨家数/MA5、容量前三、双红/新高/涨停、个股相对强度要形成推理链。
- 证据分层：区分 L1 观点、L2 基本面、L3 订单/认证/量产/客户验证/反证、L4 盘面强度。
- 生命周期：回答阶段、状态变化、市场价值成绩单、升级/降级/证伪条件。
- 二阶导：从目标股反推真实产业瓶颈和更优表达。

## 用户影子反驳

- 是否只是在套模板，没有从第一性原理解释资金行为？
- 是否只看了个股，没有放进大盘、情绪、板块容量、双红题材和平行题材竞争？
- “受益”的证据是否够硬，还是只有 L1 观点和题材标签？
- 目标是不是这条链的最优表达，市场正在奖励谁、抛弃谁、犹豫谁？
- 逻辑生命周期到底在哪一段，相比过去 N 天是升级还是降级？
- 有没有主动寻找反证和二阶导到更好的研究队列？

## 后续升级

若二次调用仍不稳定，再升级为显式多 agent self-refine：

`draft -> checklist critique -> shadow-user critique -> revise -> score -> final`

低于阈值的回答应标记低置信或自动重写。
