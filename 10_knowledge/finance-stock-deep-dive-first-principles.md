# 金融个股深挖的第一性原理顺序

## 结论 / 要点
- 个股深挖不能从题材标签、盘面强弱或策略命中直接倒推公司价值；必须先回答“公司到底卖什么、解决什么瓶颈、在产业链哪一环、卖给谁、如何变成收入和利润”。
- 默认分析顺序：公司本体 -> 产业链位置 -> 客户/产品/收入验证 -> 同链对比 -> 炒作逻辑与生命周期 -> **市场结构推演路径** -> 板块主支线与市场环境 -> 反证与后续验证。
- 市场结构推演路径是个股深挖的强制第二层，但不能机械罗列字段。它要从策略一二三四中演化成生命周期推理：大盘处于初步走强、主升、上升后第一次分歧、反弹、反弹后兑现、探底还是冰点修复；板块处于主线启动、主升扩散、分歧承接、二阶段回流、补涨扩散还是高位兑现；个股处于核心同步走强、趋势延续、分歧回踩、低位补涨、高低切承接还是高位兑现。
- 大盘层必须看阶段、量能、涨家数、涨跌停、MA5 情绪和市场风格。MA5 情绪不是简单均线名词，而是用涨家数滚动观察情绪拐点：例如第 N+6 日的涨家数大于第 N 日，则 5 日均线会拐头向上，可辅助判断情绪是否从波谷区间转折。市场风格还要区分强度集中在大成交趋势、情绪连板、低位板块切换、高位抱团分化，还是高低切。
- 板块层必须看容量前三行业、双红题材、涨停热度、成交额/边际量、与其他平行题材的关系、是否反复双红、是否从主线扩散进入分歧或二阶段回流。不能只说“某题材双红”，要说明它是初次走强、主升延续、第一次分歧后的承接、补涨扩散，还是高位兑现。
- 个股层必须结合市场与板块阶段看相对强度：市场初步走强时是否同步走强，市场上升时是否强于板块，第一次分歧时是否抗跌或回踩到合理位置，反弹阶段是核心修复还是补涨跟随，兑现阶段是否开始放量滞涨或弱于同链。第一性原理回答“产业上为什么值得看”，市场结构推演路径回答“市场现在怎么交易它”。
- 策略一二三四是概率与时间窗口的市场结构语言，只能辅助判断个股处于启动、延续、回踩、补涨或兑现阶段，不能替代第一性产业分析。
- “深挖”必须区分三类东西：稳定事实（主营、产品、客户、收入结构）、市场正在交易的叙事（题材映射、海外对标、涨幅区间命中逻辑）、待验证假设（订单、认证、量产、收入占比、毛利率、客户导入）。
- 深挖不是只回答目标个股能不能涨，还要发散“二阶导”：沿产业链寻找真正的瓶颈、替代暴露和可能更优投资机会。例如一家公司只是弱映射时，要继续问更直接的上游材料/设备/芯片/客户/验证环节是谁，哪些公司更接近订单、认证、产能或利润弹性。
- 策略一二三四是底层方法论的衍生产物，不代表绝对收益率和正确率。agent 要学习的是其设计思路：先定义市场环境和目标函数，再选可观测变量，再做前瞻验证和失效条件，而不是把策略名当标签套到个股上。必要时可以提出“策略五”式新假设，但必须说明适用环境、变量、验证方式和反证条件。

## 背景 / 依据
- 裕太微案例中，初版回答过早使用高速互联题材、盘面相对强度和策略状态，遗漏主营、产业链上下游、客户、相关公司和逻辑生命周期，用户评分仅 60 分。
- 修正后的框架要求先说明裕太微位于以太网 PHY / 高速物理层芯片上游芯片设计环节，再拆 Marvell/Broadcom 映射、DSP 研发线索、数据中心客户验证和同链公司差异。
- 用户进一步明确：问答必须基于第一性原理出发，消化市场结构底层方法论；策略一二三四只是提供视角，agent 应能像 Serenity Alpha 一样发现产业瓶颈和更好的暴露，而不是只做给定个股的线性解释。
- 精智达案例中，产业第一性原理分析被用户评为 80 分，但缺少每日全量复盘视角：没有完整呈现大盘阶段、情绪阶段、双红题材、题材平行关系、补涨/主线/高低切、高位平行走强、逻辑生命周期和板块发展周期。该案例确立“80 分到 90 分”的关键差距：个股深挖必须把产业逻辑和市场结构推演合并。
- 精智达二次纠偏中，用户指出“市场结构推演路径”不能生硬补字段，而要学会从策略一二三四抽象底层方法论：策略一/四体现市场走强与强趋势核心，策略二体现弱市题材确认和低位补涨，策略三体现前强核心分歧回踩后的修复；这些都要服务于大盘-板块-个股的生命周期判断。
- 可迁移到所有 A 股个股深挖，尤其是多题材叠加、海外对标、AI 产业链映射、尚未完成 L3 事实验证的标的。
