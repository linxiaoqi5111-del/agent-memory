# 金融个股深挖的第一性原理顺序

## 结论 / 要点
- 个股深挖不能从题材标签、盘面强弱或策略命中直接倒推公司价值；必须先回答“公司到底卖什么、解决什么瓶颈、在产业链哪一环、卖给谁、如何变成收入和利润”。
- 默认分析顺序：公司本体 -> 产业链位置 -> 客户/产品/收入验证 -> 同链对比 -> 炒作逻辑与生命周期 -> 板块主支线与市场环境 -> 反证与后续验证。
- 策略一二三四是概率与时间窗口的市场结构语言，只能辅助判断个股处于启动、延续、回踩、补涨或兑现阶段，不能替代第一性产业分析。
- “深挖”必须区分三类东西：稳定事实（主营、产品、客户、收入结构）、市场正在交易的叙事（题材映射、海外对标、涨幅区间命中逻辑）、待验证假设（订单、认证、量产、收入占比、毛利率、客户导入）。
- 深挖不是只回答目标个股能不能涨，还要发散“二阶导”：沿产业链寻找真正的瓶颈、替代暴露和可能更优投资机会。例如一家公司只是弱映射时，要继续问更直接的上游材料/设备/芯片/客户/验证环节是谁，哪些公司更接近订单、认证、产能或利润弹性。
- 策略一二三四是底层方法论的衍生产物，不代表绝对收益率和正确率。agent 要学习的是其设计思路：先定义市场环境和目标函数，再选可观测变量，再做前瞻验证和失效条件，而不是把策略名当标签套到个股上。必要时可以提出“策略五”式新假设，但必须说明适用环境、变量、验证方式和反证条件。

## 背景 / 依据
- 裕太微案例中，初版回答过早使用高速互联题材、盘面相对强度和策略状态，遗漏主营、产业链上下游、客户、相关公司和逻辑生命周期，用户评分仅 60 分。
- 修正后的框架要求先说明裕太微位于以太网 PHY / 高速物理层芯片上游芯片设计环节，再拆 Marvell/Broadcom 映射、DSP 研发线索、数据中心客户验证和同链公司差异。
- 用户进一步明确：问答必须基于第一性原理出发，消化复盘会底层方法论；策略一二三四只是提供视角，agent 应能像 Serenity Alpha 一样发现产业瓶颈和更好的暴露，而不是只做给定个股的线性解释。
- 可迁移到所有 A 股个股深挖，尤其是多题材叠加、海外对标、AI 产业链映射、尚未完成 L3 事实验证的标的。
