# 金融 Agent 晚间卖方与机构胜率发散框架

## 结论 / 要点

- 机构胜率不是买入信号，而是卖方信息权重调节器。
- 晚间卖方发散必须同时看四个维度：机构胜率、覆盖密度、证据硬度、盘面位置。
- 高胜率机构推低覆盖硬事实，优先进入研究发散；高胜率机构推高覆盖共识，应先反向审稿，防止变成兑现风险。
- T+5 强但 T+10 衰减，通常偏短催化/情绪点火；T+5 和 T+10 都强，才更像可延续的中短期趋势。
- 发散要沿产业瓶颈走，不沿研报标题走：从涨价、缺货、交期、订单、客户认证、扩产、资本开支反推设备、材料、零部件、封测、供电、耗材等更直接环节。

## 背景 / 依据

`finance-workspace-private` 已有 `opinion-cross` / `opinion-store` / `winrate_rank.py`，可以统计卖方来源在 T+3/5/7/10 窗口相对沪深300的超额胜率。用户希望后续问答不只是复述晚间卖方研报，而是结合高胜率机构正在推的方向，做二阶导和产业瓶颈发散。

本框架的稳定判断是：

1. 先判断机构擅长的时间窗口，而不是直接看它推什么股票。
2. 再判断观点是否已经卖方扎堆；第 1 篇可能是信息差，第 N 篇可能是反向信号。
3. 再判断证据硬度：公告、订单、涨价函、交期、客户认证、扩产等强于框架性周观点。
4. 最后回到盘面，确认方向是否进入双红、容量行业、新高集群、涨停热度或强势股榜。

## 输出规范

后续回答“晚间卖方怎么看 / 胜率高的机构推什么 / 卖方研报做发散”时，输出应自然但必须覆盖：

- 哪些是优先发散：高胜率 + 低覆盖 + 硬事实 + 盘面未充分反映。
- 哪些只作确认：逻辑真但覆盖密度高、卖方扎堆、盘面已演绎。
- 哪些反向谨慎：短窗胜率强但中窗衰减、覆盖极高、或盘面已经兑现。
- 二阶导：从事实反推产业瓶颈，而不是沿研报标题找同概念股。
- 验证点：订单、客户认证、涨价持续性、交期、扩产落地、毛利率修复、盘面双红/新高/涨停确认。
