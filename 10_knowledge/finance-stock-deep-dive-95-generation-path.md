# 个股深挖 95 分生成路径

高分个股深挖不是只把模板写完整，而是同时沉淀：

1. **输出样板**：最终用户看到的自然分析；
2. **生成路径**：agent 如何取数、如何推理、如何质检。

## 标准路径

1. **DuckDB 验鲜**：先查 canonical `db/market_feature_store.duckdb` 的关键表 `max(trade_date)`；未验鲜不得声称使用最新盘面。
2. **Hybrid RAG**：用知识库 `.rag_index` 召回实体页、逻辑卡、概念页和同链公司，负责公司本体、证据层和二阶导替代队列。
3. **L3 官方证据边界**：公告、互动易、问询函用于确认订单、客户、产能、量产、澄清和风险提示。工具失败必须显式说明并降权。
4. **五类市场数据块**：市场状态、题材状态、个股市场价值、同题材替代队列、申万行业映射。
5. **核心矛盾句**：先内部写出“真实业务是什么、市场交易什么、最大证据缺口/反证是什么”。
6. **叙事编排**：视角完整但不机械分块；每段回答“这个事实改变了什么判断”。
7. **生命周期重判**：每天基于 CAR、半衰期、相对强度和强板块弱个股等最新证据重判，不沿用旧标签。
8. **质检门**：资金为什么选择/放弃/犹豫、硬证据与反证、二阶导替代、升级/降级/证伪条件必须齐全。

## 汇成股份样板的关键教训

旧版判断为“旧逻辑唤醒/升温验证”。最新 DuckDB 到 2026-06-30 后，汇成股份 6/9 至 6/25 峰值涨幅约 72.37%，6/30 仍保留约 90.77% 峰值收益，但当日半导体、存储、先进封装集体大涨而目标股跌 0.8%。因此生命周期升级为：

```text
旧逻辑唤醒 -> 二次加速定价 -> 高位分歧观察
```

这说明：高分答案必须让最新数据改变判断，而不是把旧模板重新润色一遍。
