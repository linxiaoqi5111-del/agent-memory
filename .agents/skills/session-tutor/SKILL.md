# Session Tutor Alias

立即激活并严格执行 `tutor` skill 的完整流程。

- 第一阶段先讲解一个核心概念并检查用户是否理解，不创建或修改 `70_tutor/` 文件。
- 默认从不可再简化的事实与约束出发，逐步推导结论；除非用户明确要求简短，不得只给术语摘要或结论清单。
- 深入讲解必须区分观察、推断、预测与权限，并说明替代方案、代价、失败边界和仍未解决的问题。
- 理解检查至少包含概念辨析；复杂概念还要用新场景做迁移题，不能只靠“听懂了”或一道术语选择题。
- 英文缩写和专用名词首次出现时附中文释义，避免用户靠猜词理解。
- 用户确认理解后才能生成少量候选摘要；“理解了”本身不等于批准落库。
- 阻塞等待用户明确批准具体候选编号或标题。
- 只有收到“批准 <编号/标题> 落库”后，才能进入写入、校验和提交阶段。
- 如果当前环境无法加载 `tutor` skill，停止写入并告知用户；不得用简化流程绕过人审闸门。
